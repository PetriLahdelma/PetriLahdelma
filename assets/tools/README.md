Tool logo sources
=================

Codex, OpenAI (used for ChatGPT), and Figma marks are from Lobe Icons, commit c385b2b8d1f9e19aa86e628d4e23c91ee1111a47:
https://github.com/lobehub/lobe-icons/tree/c385b2b8d1f9e19aa86e628d4e23c91ee1111a47/packages/static-svg/icons

Claude uses the complete official rounded app icon from Anthropic’s press kit, retrieved 6 October 2026:
https://anthropic.com/press-kit
Archive path: Anthropic media resources/Anthropic logos/Claude logos/4 Claude icon/SVG/ClaudeIcon-Rounded.svg

Storybook uses its official brand asset:
https://github.com/storybookjs/brand/blob/main/icon/icon-storybook-default.svg

Claude’s official app icon is preserved unchanged. Codex, OpenAI, Figma and Storybook are placed on light tiles for contrast in both GitHub themes. The bundled upstream licenses apply to the Lobe Icons and Storybook source assets; Claude is sourced separately from Anthropic’s press kit.

TypeScript uses the unmodified blue square mark from the official TypeScript asset pack, retrieved 7 October 2026:
https://www.typescriptlang.org/branding/
https://www.typescriptlang.org/branding/typescript-design-assets.zip
Archive asset: ts-logo-128.svg

Swift uses the unmodified full-color logo from Apple’s official Swift logo pack, retrieved 7 October 2026:
https://developer.apple.com/swift/resources/
https://developer.apple.com/swift/downloads/swift-logo.zip
Archive asset: Swift Logo/Assets/Swift logo/SVG/Swift_logo_color.svg

TypeScript and Swift retain their official shapes and colors. All seven logos use separate SVG images with matching display sizes and internal spacing. The unlinked images wrap naturally within a centered paragraph on narrow screens.
